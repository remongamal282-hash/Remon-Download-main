# Remon Download - دليل المستخدم / User Guide

هذا الدليل يشرح طريقة استخدام Remon Download وخصائصه الأساسية باللغتين العربية والإنجليزية.

---

## العربية

### 1. نبذة عن البرنامج

Remon Download هو برنامج سطح مكتب لتنزيل وإدارة فيديوهات YouTube والملفات الإعلامية. يتيح لك تحليل رابط فيديو أو قائمة تشغيل، اختيار الجودة والصيغة، إدارة عدة تنزيلات، وجدولة التنزيلات.

يدعم البرنامج:

- الفيديوهات الفردية.
- YouTube Shorts.
- قوائم التشغيل Playlists.
- اختيار فيديوهات محددة من قائمة تشغيل أو قناة.
- تنزيل الفيديو أو الصوت بصيغ متعددة.
- إيقاف التنزيل واستكماله وإلغاؤه وإعادة المحاولة.
- سجل التنزيلات والمفضلة.
- التنزيلات المجدولة.
- اللغة العربية والإنجليزية واتجاه RTL/LTR.
- الوضع الفاتح والداكن ووضع النظام.
- العمل في الخلفية وشريط النظام عند تفعيل الإعداد المناسب.

### 2. التثبيت

1. شغّل ملف التثبيت `Remon-Download-Setup-<version>.exe`.
2. اختر مكان التثبيت عند الحاجة.
3. أكمل خطوات معالج التثبيت.
4. شغّل Remon Download من اختصار سطح المكتب أو قائمة Start.

نسخة Windows الرسمية تتضمن أدوات التشغيل اللازمة للتنزيل: `yt-dlp.exe` و`ffmpeg.exe` و`ffprobe.exe`.

### 3. لوحة التحكم وتحليل الرابط

1. افتح صفحة **لوحة التحكم**.
2. الصق رابط YouTube في حقل الرابط.
3. اضغط **تحليل**، أو انتظر التحليل التلقائي بعد إدخال رابط صحيح.
4. راجع بيانات الفيديو أو القائمة الناتجة.
5. للفيديو الفردي، اختر الجودة والصيغة ثم اضغط **إضافة إلى قائمة التنزيل**.
6. للقائمة أو القناة، حدد الفيديوهات المطلوبة ثم اضغط إضافة المحدد، أو أضف الكل.

إذا كان الرابط غير صالح أو غير مدعوم، يعرض البرنامج رسالة خطأ ويمكنك إدخال رابط آخر.

### 4. قائمة التنزيل

تظهر العناصر المضافة في صفحة **قائمة التنزيل**. لكل عنصر يمكنك:

- متابعة نسبة التقدم والحجم والسرعة والوقت المتبقي.
- إيقاف التنزيل مؤقتًا.
- استكمال التنزيل.
- إلغاء التنزيل.
- إعادة محاولة التنزيل الفاشل أو الملغى.
- حذف العنصر من القائمة.
- فتح مجلد التنزيل بعد اكتماله.
- تغيير ترتيب العناصر بالسحب والإفلات.

يمكنك أيضًا تحديد:

- عدد التنزيلات المتزامنة.
- حد سرعة التنزيل.

يتم تشغيل التنزيلات حسب ترتيبها وعدد الفتحات المتاحة.

### 5. السجل

صفحة **السجل** تعرض التنزيلات المكتملة والفاشلة والملغاة. من خلالها يمكنك:

- مراجعة تفاصيل التنزيل.
- إعادة تنزيل عنصر سابق.
- فتح مجلد الملف.
- حذف عنصر واحد أو تنظيف السجل.

### 6. المفضلة

صفحة **المفضلة** تحفظ العناصر التي تريد الرجوع إليها لاحقًا. يمكنك:

- تنزيل عنصر من المفضلة مرة أخرى.
- إزالة عنصر من المفضلة.
- مراجعة العنوان والصورة والرابط.

### 7. التنزيلات المجدولة

لإنشاء تنزيل مجدول:

1. افتح صفحة **المجدول**.
2. أدخل رابط الفيديو.
3. اختر التاريخ.
4. اختر الوقت.
5. اختر التكرار: مرة واحدة، يوميًا، أو أسبوعيًا.
6. اضغط **إنشاء**.

عند حلول الموعد، يضيف البرنامج التنزيل إلى قائمة التنزيلات. يمكنك إلغاء أو حذف الجدول من الصفحة نفسها.

### 8. الإعدادات

يتم حفظ الإعدادات تلقائيًا.

#### الإعدادات العامة

- **مجلد التنزيل:** المجلد الذي تحفظ فيه الملفات.
- **البدء مع Windows:** عند تفعيله يبدأ البرنامج تلقائيًا مع تشغيل Windows.
- **التصغير إلى شريط النظام:** عند تفعيله يؤدي زر الإغلاق إلى إخفاء النافذة مع استمرار البرنامج في العمل بجوار الساعة. زر التصغير العادي يبقي البرنامج ظاهرًا في شريط المهام.

#### المظهر واللغة

- اختيار الوضع الفاتح أو الداكن أو وضع النظام.
- اختيار العربية أو الإنجليزية.
- تتغير جهة الواجهة تلقائيًا إلى RTL للعربية وLTR للإنجليزية.

#### إعدادات التنزيل

- عدد التنزيلات المتزامنة.
- حد السرعة.
- الجودة الافتراضية.
- صيغة الفيديو الافتراضية.
- صيغة الصوت الافتراضية.

#### الإشعارات

يمكنك تفعيل أو تعطيل الإشعارات، وكذلك تحديد إشعارات اكتمال التنزيل أو فشله.

#### الحافظة

تحتوي الصفحة على إعدادات مراقبة الحافظة وخيار طلب التأكيد قبل التنزيل، حسب إصدار البرنامج والإعدادات المتاحة.

#### الإعدادات المتقدمة

- مسار `yt-dlp` المخصص.
- مسار `FFmpeg` المخصص.
- إعداد Proxy عند الحاجة.

#### تسمية الملفات

يمكن تخصيص قالب اسم الملف. من الرموز المدعومة:

- `%(uploader)s` اسم القناة.
- `%(title)s` عنوان الفيديو.
- `%(resolution)s` الدقة.
- `%(ext)s` امتداد الملف.

يعرض البرنامج معاينة مباشرة لاسم الملف الناتج.

### 9. شريط المهام وشريط النظام

- زر التصغير يصغّر النافذة إلى شريط مهام Windows، ويبقى البرنامج مفتوحًا.
- عند تفعيل **التصغير إلى شريط النظام**، يؤدي زر الإغلاق إلى إخفاء البرنامج بدل إنهائه.
- يمكن إعادة إظهار البرنامج من أيقونته بجوار الساعة.
- إغلاق البرنامج من قائمة أيقونة شريط النظام ينهي البرنامج فعليًا.
- التنزيلات والجدولة تستمران أثناء إخفاء النافذة.

### 10. تغيير اللغة أو إعادة الإعدادات

لتغيير اللغة، افتح **الإعدادات > المظهر** واختر العربية أو الإنجليزية.

لإرجاع الإعدادات الافتراضية، اضغط **إعادة ضبط الإعدادات**. سيؤدي ذلك إلى إعادة جميع خيارات البرنامج إلى القيم الافتراضية، بما فيها تشغيل البرنامج مع Windows والتصغير إلى شريط النظام.

### 11. استكشاف الأخطاء

- **الرابط غير صالح:** تأكد من نسخ رابط YouTube كاملًا.
- **الفيديو غير متاح:** قد يكون الفيديو خاصًا أو محذوفًا أو محجوبًا.
- **التنزيل لا يبدأ:** تحقق من مجلد التنزيل والمساحة المتاحة وصلاحيات الكتابة.
- **مشكلة في التحويل:** تحقق من مسار FFmpeg من الإعدادات المتقدمة.
- **عدم بدء البرنامج مع Windows:** تأكد من تفعيل خيار البدء مع Windows ثم أعد تسجيل الدخول إلى Windows.
- **البرنامج مخفي:** افحص شريط المهام أو أيقونة Remon Download بجوار الساعة.

### 12. حول البرنامج

تعرض صفحة **حول** اسم البرنامج والإصدار ومعلومات المطور وبيانات التواصل المتاحة.

## English

### 1. About the application

Remon Download is a Windows desktop application for downloading and managing YouTube videos and media files. It can analyze a video or playlist URL, select quality and format, manage multiple downloads, and schedule downloads.

The application supports:

- Individual videos.
- YouTube Shorts.
- Playlists.
- Selecting specific videos from a playlist or channel.
- Video and audio downloads in multiple formats.
- Pause, resume, cancel, and retry actions.
- Download history and favorites.
- Scheduled downloads.
- Arabic and English with RTL/LTR layout support.
- Light, dark, and system themes.
- Background operation and system tray behavior when enabled.

### 2. Installation

1. Run `Remon-Download-Setup-<version>.exe`.
2. Choose the installation location if needed.
3. Complete the installation wizard.
4. Launch Remon Download from the desktop shortcut or the Start menu.

The official Windows build includes the required download tools: `yt-dlp.exe`, `ffmpeg.exe`, and `ffprobe.exe`.

### 3. Dashboard and URL analysis

1. Open the **Dashboard** page.
2. Paste a YouTube URL into the URL field.
3. Click **Analyze**, or wait for automatic analysis after entering a valid URL.
4. Review the returned video or playlist information.
5. For a single video, select the quality and format, then click **Add to Queue**.
6. For a playlist or channel, select the videos you need and add the selected items, or add all items.

If the URL is invalid or unsupported, the application shows an error and allows you to enter another URL.

### 4. Download queue

The **Queue** page displays all added items. For each item, you can:

- Monitor progress, size, speed, and remaining time.
- Pause the download.
- Resume the download.
- Cancel the download.
- Retry a failed or canceled download.
- Remove the item from the queue.
- Open the download folder after completion.
- Reorder items using drag and drop.

You can also configure:

- The number of concurrent downloads.
- The download speed limit.

Downloads start according to their order and the available concurrent slots.

### 5. History

The **History** page contains completed, failed, and canceled downloads. You can:

- Review download details.
- Download an item again.
- Open the file folder.
- Remove one item or clear the history.

### 6. Favorites

The **Favorites** page stores items you want to keep for later. You can:

- Download a favorite item again.
- Remove an item from favorites.
- Review its title, thumbnail, and URL.

### 7. Scheduled downloads

To create a scheduled download:

1. Open the **Scheduler** page.
2. Enter the video URL.
3. Select a date.
4. Select a time.
5. Choose the repeat option: once, daily, or weekly.
6. Click **Create**.

When the scheduled time arrives, the application adds the download to the queue. You can cancel or remove the schedule from the same page.

### 8. Settings

Settings are saved automatically.

#### General settings

- **Download folder:** The folder used to save downloaded files.
- **Start with Windows:** When enabled, the application starts automatically when Windows starts.
- **Minimize to system tray:** When enabled, the close button hides the window while the application continues running in the system tray. The normal minimize button keeps the application visible in the taskbar.

#### Appearance and language

- Choose light, dark, or system theme.
- Choose English or Arabic.
- The layout automatically uses LTR for English and RTL for Arabic.

#### Download settings

- Number of concurrent downloads.
- Speed limit.
- Default quality.
- Default video format.
- Default audio format.

#### Notifications

You can enable or disable notifications and choose whether to receive notifications when downloads complete or fail.

#### Clipboard

The settings page contains clipboard monitoring and ask-before-downloading options, depending on the application version and available behavior.

#### Advanced settings

- Custom `yt-dlp` path.
- Custom `FFmpeg` path.
- Proxy configuration when needed.

#### File naming

You can customize the output filename template. Supported tokens include:

- `%(uploader)s` channel name.
- `%(title)s` video title.
- `%(resolution)s` video resolution.
- `%(ext)s` file extension.

The application shows a live preview of the resulting filename.

### 9. Taskbar and system tray

- The minimize button minimizes the window to the Windows taskbar and keeps the application running.
- When **Minimize to system tray** is enabled, the close button hides the application instead of terminating it.
- You can show the application again from its icon near the clock.
- Choosing Quit from the system tray menu fully exits the application.
- Downloads and scheduled tasks continue while the window is hidden.

### 10. Changing language or resetting settings

To change the language, open **Settings > Appearance** and choose Arabic or English.

To restore default settings, click **Reset Settings**. This restores all application options, including Start with Windows and Minimize to system tray.

### 11. Troubleshooting

- **Invalid URL:** Make sure you copied a complete YouTube URL.
- **Video unavailable:** The video may be private, deleted, or restricted.
- **Download does not start:** Check the download folder, available disk space, and write permissions.
- **Conversion problem:** Check the FFmpeg path under Advanced settings.
- **Application does not start with Windows:** Confirm that Start with Windows is enabled, then sign out and sign in to Windows again.
- **Application is hidden:** Check the taskbar or the Remon Download icon near the clock.

### 12. About

The **About** page displays the application name, version, developer information, and available contact details.

## Support checklist / قائمة معلومات الدعم

When reporting a problem, include:

- Application version.
- Windows version.
- The page where the problem occurred.
- The exact URL type: video, Shorts, playlist, or channel.
- The visible error message.
- Whether the problem occurs in the installed version or development version.
